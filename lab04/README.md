\# lab04 — Обработка журнала метеостанции



\## Файлы



\- `stats.py` — разбор записей, проверка данных, расчёт средних температур и поиск самого тёплого города.

\- `main.py` — чтение журнала и вывод отчёта.



\## Формат входных данных



Каждая запись содержит город, температуру и дату через точку с запятой:



`город;температура;дата`



\## Запуск



```bash

python main.py

```



Программа читает данные из стандартного ввода и выводит три строки:

1\. Количество корректных записей.

2\. Количество пропущенных непустых записей.

3\. Средняя температура самого тёплого города.
