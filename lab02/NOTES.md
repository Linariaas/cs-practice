# Git

## Рабочая папка

Рабочая папка — это файлы проекта, с которыми я сейчас работаю.
Изменения в этих файлах ещё не обязательно подготовлены к сохранению в истории Git.

## Индекс

Индекс — это область, куда мы помещаем изменения, которые хотим включить в следующий коммит.
Команда git add добавляет изменения в индекс.

## Коммит

Коммит — это сохранённая в истории Git версия подготовленных изменений.
У коммита есть сообщение, по которому можно понять, что было изменено.
15:15

## Различия Git и GitHub

Git — это система контроля версий, которая работает локально на компьютере.
GitHub — это сервис, где можно хранить удалённые Git-репозитории и работать с ними совместно.

## Использованные команды

### git status

Показывает текущее состояние рабочей папки и индекса:
изменённые, новые и подготовленные файлы.

### git diff

Показывает изменения в рабочей папке, которые ещё не добавлены в индекс.

### git diff --staged

Показывает изменения, уже добавленные в индекс и готовые к коммиту.


## Ветки

Ветка — это отдельная линия разработки в Git, которая указывает на определённую последовательность коммитов.

При создании нового коммита ветка перемещается и начинает указывать на этот новый коммит.

Слияние (merge) объединяет изменения из одной ветки с другой.
