# Git branches

Ветка — это отдельная линия разработки.

`main` — основная ветка проекта.

Команда `git switch -c explain-branches` создаёт новую ветку и сразу переключает на неё.

Изменения, сделанные в `explain-branches`, можно разрабатывать независимо от `main`, а затем объединить ветки с помощью `git merge`.
