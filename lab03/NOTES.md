\# Git workshop



\## git diff

Показывает различия между состояниями файлов.



\## git show

Показывает конкретный коммит и изменения, которые он содержит.



\## git log

Показывает историю коммитов.



\## git log -S

Ищет коммиты, в которых изменился указанный текст.



\## git blame

Показывает, какой коммит изменил каждую строку файла
